# Wikipedia Research Agent

A simple Python agent that uses **Google Gemini** (via Agno) and **WikipediaTools** to fetch and summarize key points from Wikipedia topics.

---

## 🧩 Features
- Uses **Gemini 2.0 Flash** for natural language understanding  
- Integrates **WikipediaTools** for live Wikipedia searches  
- Outputs responses in clean, Markdown-formatted text
